# Instructions
Your task is to summarize the feedback generated by the synthetic personas.

1. Read all the markdown files in the `output/` folder (excluding any previous summary files).
2. Synthesize the feedback, highlighting common themes, unique insights, and polarized opinions.
3. Write the summary in markdown format to a file in the `output/` folder named `summary.md`.
4. The summary should be objective, concise, and structured.
